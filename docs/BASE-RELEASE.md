# KL Play 0.5.0-rc.1

Primeira candidata pública, baseada no Lemuroid. Biblioteca com capas personalizadas, editor de skins, temas, avanço rápido solicitado de 2x a 8x, cheats conforme compatibilidade do núcleo, perfil local, Sii, diário e sequência de dias jogados.

Cabo GBA experimental: 2 jogadores ARM64 no modo Multi-Pak. Mario Kart: Super Circuit funcionou no teste do criador; Pokémon Quetzal falhou. Google e GitHub ainda estão em preparação. Não inclui ROMs/BIOS. Desempenho depende do dispositivo e do jogo.

Problema conhecido: foi relatado crash de GBA em avanço rápido 8x. A atualização Plus revisa o áudio e a mudança de velocidade. Não use esta release como evidência de estabilidade de 8x.
